## Traqula
{:#implementation}

[Traqula](TODO: cite) is a modular framework for query parsing, generation and transformation.
Using Traqula, parsers, generators and query transformers can be created by taking an existing component and manipulating it to create a new version.
This composability is achieved by modeling grammar rules and their counterparts as first class citizens,
and by allowing construction and manipulation though the builder design pattern.

Parser and generator rules, as well as transformation steps are simple objects identified by a name and an implementation.
At run time, when a rule calls another rule, it performs a name based lookup to call the subrule.
Using this approach, rules can simply be added, patched or removed form the parser, generator or transformer.

Traqula currently supports parsing transforming and generating SPARQL 1.1, SPARQL 1.1 + ADJUST, and SPARQL 1.2,
and through its modularity dependent projects can easilly create their own parsing components starting from those supported by Traqula.
Within [Comunica](cite:cites comunica) for example, Traqula has been used to implement an open algebraic model such that new algebra operations can easily be introduced.
