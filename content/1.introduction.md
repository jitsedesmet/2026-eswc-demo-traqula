## Introduction
{:#introduction}

Querying [RDF]() data is typically done using the [SPARQL query language]().
For well over a decade now, RDF has remained unchanged; and so has it's query language SPARQL.
With the finalization of both [RDF 1.2]() and the accompanying [SPARQL 1.2]() specification,
many application will choose to migrate, while others will not since migration is not necessarily trivial.
Namely, RDF 1.2 introduces the concept of triple terms,
enabling the creation of triples which have a triple in the object position.
This recursive chaining of triples in the object of other triple can be done indefinitely.
Since reification using triple terms is now a first class citizen,
datasets which modeled reification in RDF1.1 will likely
want to change their data-model significantly as to use RDF 1.2's dedicated syntax,
increasing adoption workload.
