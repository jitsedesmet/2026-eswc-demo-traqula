Linked Data and SPARQL are increasingly diverse, with engines supporting different dialects and extensions.
With SPARQL 1.2 nearing completion and the subsequent maintenance mode this diversity is projected to grow.
As a result, there is a need for language tools that support multiple versions and dialects, unifying them. 
As a response, we introduced Traqula, a modular parser, generator and transformer framework,
allowing you to create these components by modularly declaring them.
In this paper we showcase a Web client that uses Traqula and the modular Comunica query engine,
showcasing how both can be configured in a modular way and highlighting the importance of modularity on both language tools and query engines.
