## Demonstration
{:#demo}

<!-- Demo submissions must additionally provide a description of the demonstration that will be given at the conference (which may include screenshots and must include either a link to an online demo or to a video presenting it).  -->


In this demonstration,
we provide the opportunity for the user to configure the parsing software and query engine configuration they use.
The user can select for both parsing software and query engine whether they would like to extend the SPARQL 1.1 setup with:
1. SPARQL 1.2 functionality,
2. builtin function ADJUST, and
3. lateral operation.

Based on the options selected, the user will see the configuration files for that configuration (dynamically generated).
Specifically, we will show for Traqula how the builders for the lexer, parser, generator, toAst and fromAst transformer is manipulated.
Meanwhile, Comunica uses [Components.js](TODO: cite) as a dependency injection framework, so we show the relevant components.js config files.

After configuring both Traqula and Comunica,
the user can perform federated queries using the selected configuration within the provided webUI.
Through the execution, a mismatch between supported features is of additional interest since either the parser, 
or the engine can fail in case features are used but not configured.
